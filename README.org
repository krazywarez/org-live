#+title: org-live

* what
org-live is a live environment for writing and editing org-mode.
https://org.krz.sh

* does
- plain text editor with capitalization, autocorrect, spellcheck
- html output of the written org-mode
- download the org-mode to a file
- download the parsed html to a file

* screenshots
- screenshots/light_preview.png
- screenshots/dark_preview.png

* build
Swift compiled to WebAssembly with [[https://elementary.codes][ElementaryUI]],
rendering with [[https://gitbay.org/krz/org-swift][OrgSwift]].

Requires the swift.org 6.4.2 toolchain, the 6.4.2 Wasm SDKs, and org-swift
checked out at =../org-swift=.

#+begin_src sh
npm ci
npm run build    # writes dist/
#+end_src

The page needs =script-src 'self' 'wasm-unsafe-eval'= if served with a CSP.
